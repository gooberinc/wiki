Server compilation

Requirements

Before running the application, ensure that you have the following:

  • Go 1.20 or higher
  • Git

Compilation Instructions

  1. Compile the application Run this in your Terminal of choice. go build -ldflags "-X main.BuildDate=$(date -u +'%Y-%m-%dT%H:%M:%SZ') -X main.BuildBranch=$(git rev-parse --abbrev-ref HEAD)"

  2. Run the compiled executable After compilation, you can run it directly: ./goober-central Or if you're a Windows user: goober-central.exe

Cross-Compilation

  1. Cross-Compilation If you want to compile the application for a different operating system or architecture, use the GOOS and GOARCH environment variables. For example, to compile for Windows on a Linux machine: GOOS=windows GOARCH=amd64 go build -o goober-central.exe
